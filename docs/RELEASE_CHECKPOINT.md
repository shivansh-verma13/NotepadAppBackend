## Recovery continuation: authenticated same-origin proxy
Proposal: trust a fixed number of forwarded-IP hops, or use a Netlify function to attest its platform-provided context.ip with an independent server-only HMAC credential. Challenge: direct Render access and differing CDN/proxy paths make a hop-count assumption spoofable or pool users. Decision: use the authenticated function; Express trust proxy stays false. Render validates an IP, a 30-second timestamp, method and full request path before selecting the bounded per-process budget. Production startup requires NOTES_PROXY_SECRET (32+ characters).
